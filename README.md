# 🎙️ Nexlio Voice Studio

Free AI voiceovers, voice design and voice cloning in 30 languages, by [Nexlio](https://nexlio.cc).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/hex3132/nexlio-voice-studio/blob/main/Nexlio_Voice_Studio.ipynb)

## Features
- 🗣️ **Text to Speech**: turn any ad script into a natural voiceover
- 🎨 **Voice Design**: create a voice from a description
- 🧬 **Voice Cloning**: clone a voice from a 5–20 second sample
- 🏆 **Ultimate Cloning**: sample plus transcript for the closest match
- 🌍 30 languages · 48 kHz audio · runs free on a Colab T4 GPU

## How to use
1. Click **Open in Colab** above
2. **Runtime → Change runtime type → T4 GPU**
3. **Runtime → Run all**
4. Open the **gradio.live** link at the bottom

## Responsible use
Only clone your own voice or voices you have clear permission to use.
